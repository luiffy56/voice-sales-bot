# Aarav – AI Voice Sales Bot (FlowDesk demo)

Browser voice bot: speaks, listens, shows live chat, records the call, writes an AI summary, assigns a sales status and keeps call history.

## Deploy in about 10 minutes (free)

1. Get a free Gemini API key at https://aistudio.google.com/apikey
2. Put this folder in a new GitHub repo (index.html and api/chat.js at the top level).
3. Go to https://vercel.com, sign in with GitHub, click Add New > Project, pick the repo, then open Environment Variables and add:
   - `GEMINI_API_KEY` = your key
   - (optional) `GEMINI_MODEL` = e.g. `gemini-2.0-flash`. If a model name stops working, use any current Flash model from AI Studio.
4. Deploy. Open the link in Chrome or Edge, tick the consent box, press Start Call, allow the microphone.

Local test: `npx vercel dev` (set the key with `vercel env pull` or a `.env` file).

## How it works (for your video)

- Start Call asks for recording consent, starts the mic recording (MediaRecorder).
- Bot reply is generated by Gemini through `/api/chat`, spoken with the browser's speech synthesis.
- Your voice is converted to text with the browser's speech recognition and shown live in the chat.
- End Call stops the recording, sends the transcript to Gemini for the summary, requirements, objections, next steps and one of the six statuses.
- The call, recording, transcript and summary are saved in the browser (IndexedDB) and listed under Call history with playback.

## Change the product or language

Edit the `PRODUCT`, `COMPANY` and `BOT_NAME` block at the top of `api/chat.js`. Languages: English, Hindi, Telugu (Telugu voice depends on what the device has installed).

## Video script (about 2 minutes)

1. Show the page and explain the stack in one sentence.
2. Start a call, talk to the bot, raise a price objection, then ask for a demo.
3. End the call. Show the summary, status, recording playback and call history.
4. Optional: one quick call in Hindi.

## Known limits

- Chrome or Edge recommended. Safari and Firefox have weak speech recognition.
- The recording contains the customer's microphone only. The bot's speech is kept in the transcript.
- History is stored per browser, not on a server.
